📱 Instagram — Sync automático

Con esto configurado, la app registra tus reels y mete las métricas de 24h y 48h sola, cada día a las 21:00. No tienes que hacer nada.

Cómo obtener estos datos (10 minutos):
1. Ve a developers.facebook.com → My Apps → Create App → Business
2. Añade el producto Instagram Graph API
3. En "Instagram → Basic Display" conecta tu cuenta de Instagram Business
4. Ve a Graph API Explorer → selecciona tu app → genera un token con permisos: instagram_basic, instagram_manage_insights, pages_show_list
5. Convierte a long-lived token (válido 60 días, la app lo renueva sola):
GET https://graph.facebook.com/oauth/access_token?grant_type=fb_exchange_token&client_id=APP_ID&client_secret=APP_SECRET&fb_exchange_token=TOKEN
6. Tu Account ID lo encuentras en: Instagram → Settings → Professional Dashboard → About → ID de cuenta
